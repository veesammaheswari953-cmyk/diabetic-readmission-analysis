# Diabetic Patient Readmission Prediction

Predicting whether a diabetic patient will be readmitted to hospital, using the diabetic hospital dataset.

## Files
- `project.ipynb` : complete analysis and model code
- `diabetic_data.csv` : dataset

## What I did
- Data cleaning and preprocessing
- Trained a machine learning model to predict readmission
- Identified the top 10 important features (e.g. num_lab_procedures, num_medications, time_in_hospital)

## How to run
1. Install: `pip install pandas numpy scikit-learn matplotlib`
2. Open `project.ipynb` in Jupyter or VS Code
3. Run all cells
